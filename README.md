# Hermes Personal

Hermes Personal is a private, self-hosted AI assistant used by a single person: its owner, Serhiy Pemakhov.

It connects to the owner's own Google account to help with everyday tasks:

- checking and sorting incoming Gmail messages;
- reading and creating Google Calendar events;
- working with the owner's Google Drive, Docs and Sheets files;
- looking up the owner's contacts.

This application is not offered to the public. It is not available to anyone except its owner.
